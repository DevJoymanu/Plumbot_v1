{% extends "bot/layouts/base.html" %} {% load static %} {% comment %} THE quotation-template builder. One template for both editors. It is the QUOTE editor's layout (`quote_flat_form.html`), because building a template is building a quote: the same cards in the same order, the same item list where what is already added stays on screen, the same totals block, and the same pinned action bar at the foot. A builder that looked like a different product taught the plumber a second set of habits for the same job. Create and edit used to be two files (835 + 972 lines) that had drifted apart the way the three quote editors had before they were unified: the edit screen printed every figure in RAND ("R 0.00") on a business quoting in US dollars, put Add Item in the card header rather than under the list, and carried a warning block the create screen had never heard of. The items are a Django FORMSET, not the quote editor's JS array — the POST is `items-0-description` and so on, and that is unchanged. Only the markup around those inputs is the quote editor's: each form is one `.pbq-item` card instead of a row in a nine-column table. `template_mode` is 'new' or 'edit'. {% endcomment %} {% block title %}{% if template_mode == 'edit' %}Edit Template{% else %}New Template{% endif %}{% endblock %} {% block extra_css %} {% include "bot/includes/quote_responsive_css.html" %} {% endblock %} {% block content %}
