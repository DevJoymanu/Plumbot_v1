Create-from-lead, standalone-new and edit used to be three separate 750-950 line templates that had drifted apart: different headers, two different preview blocks, and the edit screen had no preview at all — so the same quote looked like three different products depending on how you reached it. This is the standalone layout (the one at /quotations/new/), made the layout everywhere. It mirrors what the SECTIONED layout already does: `quote_sectioned_form.html` is one template serving the same three screens. Now both layouts work the same way, and `get_template_names()` on each view picks between them per tenant. Mode comes from `quote_mode`: new — blank standalone quote create — from a lead, prefilled from the appointment edit — an existing quote, loaded from the API The differences between the three are genuinely small (what is prefilled, where Save posts, and whether Send/Duplicate/Delete are offered), so they are `{% if %}` branches here rather than three copies of the same 800 lines. Item ids come from a monotonic nextItemId(), never Date.now() or the array index — every lookup is by id, and two items added in the same millisecond shared one (CLAUDE.md).
